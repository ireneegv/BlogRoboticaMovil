# PRÁCTICA 1
----
En esta práctica he programado una aspiradora de gama baja para que limpie la casa moviéndose de manera pseudoaleatoria, para ello he usado una máquina de estados:

----
### FORWARD:
Este estado es bastante básico. Inicia el movimiento con una velocidad lineal de 0.6 durante 2 segundos y, mientras avanza, estará continuamente comprobando si le llega una señal del láser en la que detecte un obstáculo. Para esto último analizo cada rayo del láser que no sea ni infinito ni un número extraño y compruebo la distancia a la que está el objeto detectado. Si la distancia es menor que mi umbral de 0.3, entonces pasaremos al estado BACK. En el caso de que no detecte ningún obstáculo y hayan pasado 2 segundos, cambiará al estado TURN.

----
### BACK:
Este estado es el más sencillo de todos. En este caso, al haber detectado un obstáculo, el robot retrocede con una velocidad de -0.6 durante 1.5 segundos. Una vez superado este tiempo, pasará al estado TURN.

----
### TURN:
Este estado, al igual que el de FORWARD, estará comprobando continuamente que el láser no detecte ningún obstáculo. Pero, a diferencia de FORWARD, este estado sigue el movimiento de la ecuación matemática de una espiral de Arquímedes:

```
r = r0 + k * theta 
```
Utilizará la velocidad lineal y angular para realizar el movimiento de una espiral, haciendo que el radio aumente progresivamente y permitiendo así cubrir una zona cada vez mayor.

Además, como debe ser un movimiento pseudoaleatorio, la espiral puede moverse tanto en sentido horario como antihorario cada vez que se inicia. El tiempo que permanecerá en este estado también será aleatorio, variando entre 20 y 35 segundos. Una vez acabado ese tiempo, si no ha detectado ningún obstáculo con el láser, pasará al estado FORWARD para tratar de limpiar otra zona. Si durante el movimiento en espiral detecta un obstáculo a una distancia menor de 0.3 metros, pasará directamente al estado BACK para alejarse del obstáculo.
